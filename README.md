## 판 이름
- **통합본 v0** (2026-11-10): 13개 구간을 처음 합친 판
- **통합본 v1** (2026-11-12 ~ 11-23): 11주차 인물 등록부 통합 회의 결정을 반영하고 수강생이 직접 고친 판. 11/23 동결
- **통합본 v2** (2026-11-24 ~): v1의 사본에서 시작. 지금 고치는 판
- **그래프 v1**: 통합본 v1에서 만든 그래프. 통합본이 바뀌어도 그대로 두고, 다시 만들 때는 `graph/v2/`처럼 새 폴더에 저장

## 함께 고칠 때의 약속
1. 고치기 전에 `git pull` 하기, 고친 뒤 바로 커밋 · 푸시하기 (커밋 하나에 한 가지 일)
2. 원문 글자와 문단 바꾸지 않기 — `<p>` 하나 = 위키문헌 문단 하나
3. 커밋 전에 충돌 표식 찾기: VS Code 정규식 검색 `^(<{7}|={7}|>{7})` → 0건 확인
4. 이미 올린 커밋 고쳐 쓰지 않기. 충돌이 나면 혼자 풀지 말고 이슈에 먼저 알리기
5. API 키 · 비밀번호 · Neo4j 자격 증명 파일 올리지 않기
