# 통합본 v1 변경 기록 (2026-11-12)

`무정_통합본_v1.xml`은 저장소에 있던 `무정_통합본_v0.xml`(2026-11-12 23:48 커밋 28c880d까지의 수정 포함)에 11주차(11/10) 인물 등록부 통합 회의 결정을 반영해 만들었다. 구간 파일(TEI/)에서 다시 병합하지 않았다. 변환 스크립트는 `tools/make_v1.py`, 실행 기록은 `무정_통합본_v1_변환기록.json`.

**앞으로 함께 고치는 파일은 v1이다.** v0는 기준본으로 남긴다.

## 그 밖에 고친 것
- 헤더 `respStmt` 바로 아래에 있던 `<idno>` 3개와 `<email>` 1개를 스키마가 허용하는 자리(`<name>` 안, `<note>` 안)로 옮김. 값은 바꾸지 않음. 자리표시로 보이는 값(ISNI `0000 0000 0000 0000`, `1111-1112-1113-1114`)도 그대로 둠.
- v0는 손대지 않음. v0는 헤더 자리 문제(respStmt 바로 아래의 idno · email)로 tei_all 검증은 통과하지 못함.

## 2026-11-13: 11–20 · 111–120장 구분 복원

위키문헌 [1–20장](https://ko.wikisource.org/wiki/무정/1장~20장)과 [101–120장](https://ko.wikisource.org/wiki/무정/101장~120장)의 장 구분 기호(🙝 🙟) 및 각 장 첫 문단을 통합본과 대조했다. 대상 20개 장의 시작이 모두 기존 문단의 시작과 일치하여, 문단을 나누거나 본문을 수정하지 않고 장 태그를 추가했다.

| 비교 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 11–20장 | `<div type="part" n="11-20">` 1개 | `<div type="chapter" n="11">`부터 `n="20"`까지 10개 |
| 111–120장 | `<div type="part" n="111-120">` 1개 | `<div type="chapter" n="111">`부터 `n="120"`까지 10개 |
| 장 제목 | 두 구간 모두 개별 `<head>` 없음 | `<head>11장</head>`–`<head>20장</head>`, `<head>111장</head>`–`<head>120장</head>` 추가 |
| 장 끝 | 구간 끝에만 `</div>` | 각 장 끝에 `</div>` |
| 담당자·출처 | 구간의 `resp`·`source` | 각 장에 같은 값 유지 |
| 작업 메모 | 111–120장에 장 구분 복원 필요 메모 | 완료되어 삭제 |
| 전체 장 구조 | chapter 106개 + part 2개 | chapter 126개 + part 0개, 1–126장 순서대로 존재 |
| 본문·기존 태깅 | 기존 문단·운문 및 내부 태그·속성 | 수정 전후 본문의 모든 `p`·`l` XML이 동일함 |

XML 문법 검사와 장 번호·제목·순서 검사를 통과했다. 이번 변경에서는 TEI 스키마 전체 검증을 다시 실행하지 않았다. 위의 생성 시점 검사 결과와 기존 `_검증.json`은 2026-11-12 기록이다.
